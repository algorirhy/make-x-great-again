# 延迟自动 X 拉黑

这是 `delayed-auto-block` 个人分支的侧载 Chrome / Chromium 功能，不属于上游商店版、
Firefox 或 Safari 发行版。功能默认关闭。

## 使用方式

推荐把需要自动处理的类别设为“本地隐藏”，再开启“延迟自动 X 拉黑”：

1. 命中后立即在当前浏览器隐藏，不等待网络请求；
2. 符合条件的记录进入本地持久队列；
3. 保持一个已登录、且账号与设置页绑定账号一致的 X 页面打开；
4. 扩展按限速逐个调用 X 原生拉黑。

仍配置为“X 拉黑”的即时动作继续走原有前台队列，不会被本功能减速。关闭开关只暂停
发送，不删除队列或成功记录。

## 哪些记录会处理

| 记录 | 结果 |
|---|---|
| 明确选择的本地隐藏 | 入队 |
| X 拉黑成功 | 记为成功并去重 |
| X 拉黑的网络、服务端、401/403/429 失败 | 按规则等待重试 |
| X 拉黑的其他 4xx 失败 | 记为失败，不再自动重试 |
| X 拉黑返回 404 | 记为目标不可用，不回退到 handle |
| X 静音 | 跳过 |
| 被 `autoTierMode="hide"` 封顶的动作 | 跳过，避免绕过安全策略 |
| 已在设置页“恢复显示”的记录 | 发送前取消 |

旧记录没有可靠的结构化动作结果：明确写明“静音”的记录跳过，其余有合法目标的记录
默认入队；旧版零尝试的 `legacy/succeeded` 状态会重新排队。此策略避免漏处理，但可能
让少量已在 X 端拉黑、却没有本地成功证据的账号再提交一次。

## 身份、账号和权限

- 优先使用不可变的数字 `user_id`；缺失时才使用 1～15 位字母、数字或下划线组成的
  `screen_name`。
- handle 按小写去重；同一 handle 后续获得数字 ID 时，数字 ID 状态优先。
- 开启时由设置页申请 x.com 权限并绑定最近识别到的当前 X handle。
- 每次发送前重新检查开关、绑定账号、当前登录账号、处理记录和队列状态。
- 缺少绑定账号时调度器不会自动选择当前账号；需关闭后重新开启。
- 请求由当前 X 页面直接发往 X，不经过项目服务器，也不保存密码、Cookie 或 CSRF
  Token。

只有 handle 的历史记录存在改名或重新分配风险。代码不会额外查询 X 拉黑列表或解析旧
身份，因此不保证 exactly-once。

## 调度与错误处理

- 单任务串行；多个 X 标签页通过 Web Locks 共用一个调度器；
- 每次尝试间隔随机 45～75 秒；
- 滚动 1 小时最多 60 次，滚动 24 小时最多 720 次；
- 限额在发送前预留，因此页面中断或最终安全检查取消时也可能保守地占用一次预算；
- 浏览器、页面或电脑休眠时暂停，重新打开匹配账号的 X 页面后继续；
- 401/403 停止调度，需关闭再开启；429 至少冷却 1 小时；
- 网络错误、408、425、5xx 最多尝试 3 次，退避 5 / 15 分钟；
- 页面在请求中断开时，`processing` 状态恢复为待处理；
- 前台动作若在等待期间已确认成功，旧的延迟结果不会覆盖该成功状态。

限速只降低请求突发，不能保证 X 不触发风控。X 拉黑可能解除关注关系；设置页“恢复
显示”只恢复本地内容，不会解除 X 端拉黑。

## 状态与存储

设置页显示待处理、成功、失败、目标不可用和 24 小时请求数；处理记录显示每个账号的
状态及 HTTP/尝试详情。

| 存储键 | 内容 |
|---|---|
| `xss:blocklist:v2` | 本地处理记录和结构化动作字段 |
| `xss:delayed-block:states:v2` | 队列、重试、跳过和成功状态 |
| `xss:delayed-block:meta:v1` | 请求时间戳、暂停原因和下次运行时间 |
| `xss:settings` | 开关和绑定账号 |

`xss:delayed-block:states:v1` 会在下一次写入时迁移。无效或损坏的状态行会被忽略，
并可由仍存在的处理记录重新建立。卸载扩展、清除扩展数据或删除浏览器配置会丢失本地
去重状态，但不会解除 X 端已经完成的拉黑。

商店版与侧载版存储隔离；如需迁移旧的本地隐藏记录，见
[商店版数据迁移](./DELAYED-AUTO-BLOCK-MIGRATION.md)。

## 代码与验证

- `extension/lib/delayed-block.ts`：状态、迁移、限速、重试和统计；
- `extension/entrypoints/content.ts`：调度、账号校验和发送前检查；
- `extension/lib/x-action.ts`：X 请求及跨标签页节流；
- `extension/entrypoints/options/App.tsx`：设置和状态展示。

```bash
cd extension
npm run compile
npm test
npm run build
```

自动化测试不调用真实 X 账号；X 接口变化仍需自行少量验证。
